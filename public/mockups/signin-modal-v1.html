What's wrong

  1. The cheapest path is buried last. Google is one click. Email is two fields, an eight-character rule and a mode decision — and it goes first, with Google pushed below an OR. The gate page already leads with Google, so the two auth surfaces now disagree with each other.
  2. "Free resume scoring in 60 seconds" is a number we cannot stand behind. A real scan runs 30–65s, so 60 is near the worst case sold as the promise. Unverifiable stats are exactly what the marketing rules forbid.
  3. A 190px marketing block sits between the headline and the first control. This dialog only opens because someone clicked something — they have already decided. The box spends their attention re-selling.
  4. The most persuasive sentence available is thrown away. Eight call sites pass a specific reason ("Sign in free to score your résumé against the job and unlock per-bullet fixes") and the design shows a generic "Welcome to Resunova" over it.
  5. A decision before the decision. Sign in vs Create account are the same two fields; the toggle only picks which API call fires. Supabase can tell an existing address from a new one.
  6. It scrolls. ~1,500px tall, capped at 100dvh − 2rem — on a 800px laptop the primary button starts below the fold. And the close ✕ is bottom-left.

Reproduced at the shipped sizes; the pins mark 1–4. The primary button's own contrast is fine (--on-fill landed on main) — nothing below is a colour fix.

What changed, and why each one

  1. Google leads, email is one click behind it. The resting state is a single decision, and it now matches the gate page — one shape for both auth surfaces instead of two.
  2. The eyebrow names what you clicked and the headline is the gain, taken from the reason the call site already passes. Nothing generic where something specific exists.
  3. No segmented control. "New here? Create an account" sits under the button, where it costs nothing until you need it.
  4. Three assurances, all checkable. Free, no credit card, one click — "60 seconds" is gone because we cannot source it.
  5. Close moves to the top right, where every other dialog on the web puts it.
  6. ~430px collapsed, ~620px expanded. Neither scrolls on a laptop, so the primary action is never below the fold.

⚠️ The headline copy is per-destination, the same way the gate page's is. A caller that passes no reason falls back to one honest generic line rather than a greeting.
