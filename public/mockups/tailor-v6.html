One number owns the color

Green/amber lives on the figure and its meter fill — nowhere else on the tile. The old version tinted the dot too, splitting the same signal across two places for no reason.

The figure grew, everything else shrank

96 went from 30px to 52px. The keyword count moved off the headline into a quiet corner label — still readable, no longer competing for the same first glance.

The button stopped looking like a decision

A bordered button reads as importantly as the score itself. “Re-check” is now a plain text link — still clickable, no longer visually arguing with the number above it.

The meter got thinner

7px → 4px. At tile width a fat bar reads as a second headline; thin, it reads as what it is — a footnote to the number, with the same shortlist-target marker Tailor already uses elsewhere.
