One always-visible row, one on-demand popover

Width, font size, font, and header alignment are style tuning — set once, rarely touched again. They move behind a single Aa · Display button. What stays pinned is what's checked constantly: the two content overlays and the export action.

Checkboxes become a segmented pair

Keywords and Highlights read as raw HTML checkboxes today, visually unrelated to the buttons next to them. Grouped into one pill pair they read as "what's painted on the page," matching the segmented-control language already used for the display options.

The overflow warning gets a sentence, not just a color

Today "~2 pages" is an amber pill with a tooltip nobody hovers. The status pill now names the actual overage (156px) and, when it's real, a one-line strip underneath says what to do — the same number already computed in PageFitMeter, just surfaced instead of buried in a title attribute.

Rare actions move into an overflow menu

Edit in Builder and Export DOCX are used far less often than Download. A single “…” button holds them, so the row's only unmissable button is the one most people actually want.

13 controls → 5 fixed elements

Count pill, overlay pair, Display popover, page status, Download — five things at a glance instead of thirteen, and none of them clip or wrap mid-word at the pane's real ~640px width.
